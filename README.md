# 园区访客车辆临时通行系统

零依赖（仅 Python 3.10+ 标准库）的本地演示系统：被访单位为访客申请临时通行，
门岗核车牌与批准时段放行，离场按批准时段结算超时费，车主取得电子凭证。

## 一条命令启动

```bash
./run.sh                 # 首次自动建库并写入种子数据，默认 http://127.0.0.1:8000
./run.sh --port 9000     # 指定端口
./run.sh --reset         # 重置数据并重新写入种子
```

右上角可切换四种身份（演示权限）：**门岗 / A 单位 / B 单位 / 园区管理员**。

离线重放命令行样例（独立演示库 `data/demo.db`，不影响正式库）：

```bash
python3 -m park.demo
```

## 建议演示路径

1. **邀请交付**（切「A 单位」）：填车牌、预计到离时间、楼栋、联系人 → 生成一次性通行码。
2. **门岗核验**（切「门岗」）：输通行码 + 到场车牌。页面突出显示登记车牌与批准时段，
   并展示本地生成的**车牌中段遮罩抓拍**。可依次演示：
   - 车牌录错 / 通行码转发（车牌不符 → 拒绝并留痕）；
   - 提前到达（先暂缓，联系人确认后放行）；
   - 同车牌多份邀请（按出示码入场，其余邀请留痕且不受影响）；
   - 总览页「模拟门禁离线」后核验 → 信息进本地离线队列；
     「恢复门禁在线」后门岗页一键**重放**（按实际到场时间入场，同码不重复排队）。
3. **在园车辆**：大字显示剩余时间（≤15 分钟黄色、已超时红色）；可申请异常免费放行。
4. **出场收费**：免费时间（批准时段 + 15 分钟离场宽限）与超时金额**分行列清**，
   跨夜停留按连续时长累计、每 24 小时封顶；总览页可「注入道闸卡阻」演示
   **支付后闸机未开**，收费页出现「重试开闸」，重试不重新计费、不重复扣款；
   「注入支付失败」可演示渠道失败后安全重试（不扣款）。
5. **异常复核**（切「园区管理员」）：门岗的异常免费放行申请必须在此批准/驳回，
   申请理由以完整文字展示。
6. **电子凭证 / 收费流水 / 处置记录**：凭证含批准时段、实际进出、免费与超时拆分、
   交易号和出场印章；处置记录页可查每一次异常的完整文字说明。

## 核心业务规则

- **一邀请一入场**：通行码核验通过即在 `visits` 建唯一记录，重复出示一律拒绝；
  被拒绝（车牌不符/撤销）不会消耗邀请。
- **出场回执幂等**：以 `pay-visit-<id>` 为幂等键，支付渠道与本地流水双重去重，
  回执重试只返回原交易号，绝不产生第二笔费用。
- **计费冻结**：结算时点确定金额并落盘，之后闸机卡阻重试、重复回执都不改金额。
- **单位隔离**：被访单位只能看/改本单位邀请，跨单位修改直接拒绝并留痕。
- **异常免费放行**：门岗只能申请，园区管理员复核通过后才抬杆、金额置 0。
- **离线容错**：门禁离线期间核验入 SQLite 本地队列，恢复后按 FIFO 重放，
  入场时间以入队（实际到场）时间为准。

### 超时计费（`park/billing.py`）

| 项目 | 规则 |
| --- | --- |
| 免费时间 | 批准时段分钟数 + 离场后 15 分钟宽限 |
| 超时单价 | ¥2.00/小时，不足 1 小时按 1 小时 |
| 跨夜 | 连续累计，零点不重新起算免费时段 |
| 封顶 | 超时部分每满 24 小时 ¥30.00，零头按小时单价 |

## 测试

```bash
python3 -m unittest park.tests park.tests_web -v
```

覆盖（共 32 个用例）：通行码防重与转发拒绝、提前/迟到、跨夜连续计费与 24 小时
封顶、结算金额冻结、支付失败重试、重复回执不重复收费、支付后闸机未开重试、
单位隔离（服务层 + HTTP 层）、异常放行管理员复核、离线队列去重与重放、
遮罩照片落盘。

## 目录结构

```
park/
  clock.py       时间工具与剩余时间文案
  billing.py     纯函数超时计费（免费/宽限/跨夜/封顶）
  db.py          SQLite schema（邀请、进出事件、在场、支付、复核、离线队列、闸机指令）
  adapters.py    模拟摄像头（stdlib 生成遮罩 PNG）、闸机（离线/卡阻/重试）、支付（幂等）
  service.py     全部业务规则与处置留痕
  web.py         http.server 页面（白底/深灰/园区绿）
  seed.py        种子数据（含在园、跨夜、已出场、已撤销、离线待重放）
  demo.py        离线重放命令行样例
  tests.py       服务层与计费测试
  tests_web.py   HTTP 层集成测试
run.sh           一条命令启动
data/            运行时生成：park.db、photos/（车牌遮罩 PNG）
```
